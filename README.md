# AquaGuard — Water Quality Monitoring & Complaint Management System

**Team Name: AquaDB**

## Project Overview
AquaGuard is a database-driven web application that connects water-quality monitoring, citizen complaints, and administrative response in one platform.

## Features
- Citizen login and complaint submission
- Complaint tracking and status updates
- Admin dashboard and complaint management
- Officer assignment
- Water-quality readings for pH, turbidity, TDS, and temperature
- Critical water-quality alert management
- MySQL database integration

## Technology Stack
- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL
- **Local Environment:** XAMPP and phpMyAdmin

## Setup Instructions
1. Install XAMPP and start Apache and MySQL.
2. Copy the project folder into `C:\xampp\htdocs\aquaguard`.
3. Open phpMyAdmin at `http://localhost/phpmyadmin/`.
4. Create a database named `aquaguard`.
5. Import `aquaguard_backup.sql` into the database.
6. Check the database connection settings in `config/database.php`.
7. Open `http://localhost/aquaguard/` in your browser.
